# EPYCD8-2T 风扇控制

BMC 2.20 使用 `3a/01` 写八个百分比、`3a/02` 读回；新版 `d7/da` 命令不受支持。槽位从零开始，与 SDR 显示顺序不同。

| 风扇 | 原始槽位 | 温度来源 |
| --- | --- | --- |
| CPU1_FAN1 | 0 | 可用 IPMI 温度最大值 |
| FRNT_FAN1 | 4 | P40 `21:00.0`，UUID 见 `fans.toml` |
| FRNT_FAN3 | 6 | P40 `42:00.0`，UUID 见 `fans.toml` |

槽位由 RPM 实测确认：100% 时 CPU1_FAN1 / FRNT_FAN1 / FRNT_FAN3 约为 7400 / 2700 / 2700 RPM；对应槽位降到 70% 后分别约为 5500 / 1600 / 1800 RPM。FRNT_FAN4 始终约 5900 RPM，未观察到它对所测占空比变化的响应，不能据此声称它已受 PWM 控制。

单独加载 `42:00.0` 时，FRNT_FAN3 保持 30%，提高 FRNT_FAN1 到 100% 后 GPU 仍由 61°C 升至 75°C；随后提高 FRNT_FAN3 到 100%，持续负载下 GPU 在约 60 秒内降至 61°C（约 125–132 W）。这直接确定 FRNT_FAN3 的对应关系，另一组按两卡、两风扇的对应关系确定。此前 `21:00.0` 在约 240 W 的测试中触及 80°C 截止值，不能将短时测试当成持续满载散热验收。

正常曲线与 `hosts/pve-epyc/smfc/smfc.toml` 相同：65–85°C 对应 30–75%，20 步、1°C 灵敏度、1 秒轮询、自动切手动等待 5 秒。其余受控槽位使用可用 IPMI 温度的最大值。生产保护在传感器、NVML 或控制失败及达到 90°C 时请求 100%，退出并由 systemd 重启；参数未针对持续 GPU 满载重新调优。

硬件测试只运行一轮。每次测试结束，先停止负载，再将全部八槽恢复到 30%，并用 `3a/02` 确认八字节均为 `1e`。临时负载服务不保留在正式配置中。
