# HTML 页面明暗模式规则

## 适用范围

当被要求创建新的 HTML 页面时，本规则强制生效。

## 核心要求

**必须支持明暗模式（light/dark mode）**，并跟随浏览器/系统配置自动切换。

### 实现方式

使用 CSS 媒体查询 `prefers-color-scheme`，不要使用 JS 判断或手动切换按钮（除非用户另行要求）：

```css
:root {
  --bg: #ffffff;
  --text: #1a1a1a;
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg: #1a1a1a;
    --text: #f0f0f0;
  }
}
```

- 页面背景、文字、边框等基础配色必须同时定义明暗两套值
- 优先使用 CSS 变量组织配色，避免在多处重复硬编码颜色值
- 禁止只提供单一固定主题的页面

### 例外情况

用户明确指定了固定主题（如「只要深色版」）时，按用户要求执行。
