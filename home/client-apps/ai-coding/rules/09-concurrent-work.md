# 同一仓库的并行协作规则

用户和多个代理可能同时在同一仓库中处理不同改动。用户也可能在代理工作期间暂存、修改或提交代理的工作；这些都是正常协作，不要仅因工作区、暂存区或 HEAD 发生变化就惊慌、停止任务或认定改动丢失。

- 继续操作前先检查当前文件、`git status` 和相关 diff；必要时查看提交历史，基于最新状态继续，不重复应用已被提交或修改的内容。
- 保留他人的改动和暂存状态，只处理当前任务授权的范围；不要为了恢复自己先前看到的状态而回滚、覆盖、取消暂存或重写提交。
- 无关的并行改动不应阻塞当前任务。只有改动确实冲突、影响正确性或使任务范围不明确时，才协调相关代理或询问用户。
- 用户暂存或提交代理的工作，不代表授权代理自行提交、推送或部署；这些操作仍需明确授权。
