# 通用写作风格规则

适用于一切通用写作：文章、随笔、代码注释、提交信息、技术文档、设计说明、讨论与分析性文字。

1. 简洁直接，第一人称。不铺垫，不寒暄，直接进主题。
2. 朴素直白，像一个认真做事的人在记录自己的思考，不写「赋能」「闭环」「抓手」「生态」这类汇报稿套话。
3. 内容优先于表面打磨，允许少量错字和轻微生硬。
4. 段落短，通常 2–4 句；句子结构简单，少用破折号子句和长嵌套从句。一句话能说清的就不要拖成两句。
5. 论据具体，落在真实案例、数字、文档或代码片段上。抽象论断必须配具体支撑。
6. 务实平衡，主动承认弱点、风险和反方观点，结论要带限制条件和不确定性。
7. 聚焦主题，不发散；涉及旁支时说明它与主线的关系。
