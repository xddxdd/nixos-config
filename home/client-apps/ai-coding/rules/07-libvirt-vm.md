# 隔离虚拟机使用规则

## 适用场景

开发任何涉及 **GUI** 的应用，或任何需要 **隔离环境** 的任务时，使用 `ArchLinux` 虚拟机，而非直接在当前 NixOS 主机上操作。

## 使用方式

通过 `libvirt-vm-use` MCP 服务器操作 `ArchLinux` 虚拟机：

- 截图查看虚拟机当前画面
- 通过鼠标与键盘输入操作虚拟机

## 权限

在该虚拟机内可以做任何事，包括：

- 安装与卸载程序
- 任意修改系统配置

无需担心影响当前主机。

## 访问信息

- 虚拟机配置为 **免密码自动登录**
- 也可通过 SSH 访问：`ssh lantian@198.19.100.2 -p22`
